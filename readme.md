# 🐍 Laboratorio 1: Fundamentos de Python y Análisis de Texto

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

> **Resumen:** Implementación completa de la **Laboratoria №1** de la asignatura de Programación en Python. Este proyecto desarrolla un **mini-analizador de texto** que integra conceptos fundamentales (tipos de datos, cadenas, control de flujo) con técnicas prácticas de *scraping*, procesamiento de lenguaje natural básico y criptografía elemental.

---

## 📋 Contenido del Laboratorio

Este repositorio contiene la solución a 20 tareas diseñadas para dominar los conceptos básicos de Python:

### 🔧 Configuración y Entorno
- **Tarea 1:** Configuración del entorno en Google Colab + GitLab.
- **Tarea 2:** Filosofía Python (Zen of Python).

### 📊 Tipos de Datos y Operaciones
- **Tarea 3:** Creación de "fichas de texto" con anotaciones de tipos.
- **Tarea 4:** Conversión explícita e implícita de tipos.
- **Tarea 5:** Aritmética de números complejos aplicada a señales.

### 📝 Procesamiento de Texto (NLP Básico)
- **Tarea 6-7:** Descarga (`wget`), lectura y estadísticas básicas de textos de Project Gutenberg.
- **Tarea 8:** Limpieza de datos (tokenización, eliminación de puntuación).
- **Tarea 9:** Clasificación de caracteres (letras, dígitos, espacios).
- **Tarea 10:** Detección de palabras capitalizadas.

### 🔐 Algoritmos y Lógica
- **Tarea 11:** Detección de **palíndromos** multilingües.
- **Tarea 12:** Implementación del **Cifrado César**.
- **Tarea 13:** Transformación de texto ("Strange Case").
- **Tarea 14:** Reversión de texto y orden de palabras.

### 📈 Análisis y Funciones Avanzadas
- **Tarea 15-16:** Frecuencia de palabras y Top-3 (sin diccionarios).
- **Tarea 17:** Algoritmo **Pig Latin**.
- **Tarea 18:** Parseo de URLs mediante manipulación de strings.
- **Tarea 19:** Refactorización completa en funciones modulares (`main`, `download`, `parse`).
- **Tarea 20:** Estándares **PEP 8**, control de versiones y documentación.
