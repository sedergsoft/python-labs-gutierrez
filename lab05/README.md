## Функции первого класса и декораторы регистрации
- `@strategy(name)` — реестр стратегий (Фабрика + Стратегия).
- `@timed`, `@counted`, `@retry`, `@Retry`, `@validate`, `@cached_result` — сквозная функциональность без правки функций.
- Ленивые генераторы `stream_events → with_minutes → with_severity` без промежуточных списков.

## OCP
Новая стратегия — `@strategy("new")`; новый подписчик — `bus.subscribe(...)`. `aggregate` и `MonitoringPipeline` не меняются.
